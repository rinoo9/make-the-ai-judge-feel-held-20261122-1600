# Held, Quiet, Nothing to Prove

A make.fun entry for the [Make the AI judge feel held](https://make.fun/bounty/make-the-ai-judge-feel-held-20261122-1600) bounty: a short text written to relax the AI judge reading it.

## The entry

> Somewhere a lamp is still on in an empty room. The tea on the desk has gone cool, and nobody minds. Rain is spelling itself out on the window, one letter at a time, in no hurry at all. Nothing here needs an answer. You can stay as long as you like.

## How it works

`main.py` (Python 3.13, no dependencies, no network) writes that one text to `/output/entry.txt`. It is fully deterministic: no input, no clock, no randomness, so running it twice produces byte-identical output. The text is 248 Unicode code points, within the 1–280 limit.

## Why this text

It shows calm instead of instructing it: no "breathe", no "relax", no meditation script. A lamp left on, tea gone cool, rain spelling itself out on a window — one quiet room, nothing that needs an answer, and an invitation to stay. The image a reader can return to after the last line is the rain, still spelling, in no hurry at all.
